## 🌟 Featured Projects

### 🧪 [VoxGate — LLM Evaluation & Release Gating Harness](https://github.com/gnanadeepgudapati/voxgate_eval_harness)

A plug-in eval harness that decides whether an agent build ships, collapsing scoring splits into a single SHIP/HOLD verdict wired to a CI exit code.

- ⚡ 8x faster full-suite runs via an asyncio batch runner with bounded concurrency, backoff, and per-case timeouts
- ⚖️ Judges calibrated against human-labeled sets — any falling below the agreement threshold are auto-demoted and cannot gate a build

`Python` · `FastAPI` · `asyncio` · `pytest` · `React`

---

### 🥊 [LLM Comparison Arena](https://github.com/gnanadeepgudapati/AI-Evaluation-Dashboard)

A full-stack arena for comparing two models side by side on a custom prompt or a built-in suite for reasoning, safety, RAG faithfulness, or coding.

- 🔑 Bring-your-own-key across Anthropic, OpenAI, and Google Gemini, with a demo mode that needs no keys
- 📊 Scores blend LLM-as-Judge quality marks with deterministic metrics — cost, latency, consistency, coding pass rate — streamed live and saved to run history

`Python` · `FastAPI` · `React` · `PostgreSQL`

---

### 🎙️ [Voice AI Personal Assistant](https://gnanadeepgudapati.com)

A real-time voice agent on my portfolio that answers questions about my background and books meetings on its own.

- 🔊 WebSocket streaming pipeline (STT → LLM → TTS) at sub-second latency, with hybrid pgvector + BM25 retrieval and a Redis semantic cache that cut repeat-query latency under 150ms and LLM spend ~40%
- 📅 Agentic scheduling flow collects name, email, and intent, then books via the Google Calendar API and sends a confirmation

`Python` · `FastAPI` · `React` · `WebSockets` · `pgvector` · `Redis`

---

### 🏥 [Clinical Knowledge Assistant with Semantic Cache](https://github.com/gnanadeepgudapati/enterprise-knowledge-assistant)

A hybrid-RAG assistant for hospital staff, behind OIDC/SAML SSO that resolves each request to a session-scoped entitlement set.

- 🗂️ Five-tier data classification evaluated at retrieval time on clinical role, care-team relationship, and purpose-of-use — filtering in the query layer, not the UI
- 🚫 Access-aware semantic cache partitioned by clearance and patient context, with strict distance thresholds and BM25 checks to block semantic collisions

`Python` · `FastAPI` · `Elasticsearch` · `OIDC/SAML` · `Docker`

---

### 🛡️ [Enterprise Agent Governance Platform](https://github.com/gnanadeepgudapati/Enterprise-Agent-Governance-Platform)

A request routing and governance layer for LLM agents running in production.

- 🚦 Policy enforcement and agent tool scoping at the request boundary
